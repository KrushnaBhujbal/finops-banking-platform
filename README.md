# FinOps Banking Platform

The project simulating a 30+ microservice banking platform on AWS EKS,
built to practice production-grade DevOps: Terraform modules/workspaces,
Helm, hybrid K8s (EKS + local kind cluster), GitOps via ArgoCD, GitHub
Actions CI/CD, observability (ELK + Prometheus/Grafana) with SLI/SLO/SLA
tracking, and FinOps cost governance.
